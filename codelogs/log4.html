CSS Colors

Colors are used to make your page more vibrant and lively, help it to stand out in a sea of black text on white background. Gives you a little break from the monotany. It can also look terribly garish and be difficult to read when overused, which it probably will here becuase I'm gonna overuse the hell outta 'em.

Color Properties

Color can be used on text using the { color } property, on the background using the { background-color } property, and on the border of your element using the { border-color } property.

p { color: red; background-color: #4287f5; border-color: rgb(255 225 0); }

Types of Color

You're probably wondering why three very different formats for the color code example above (I know you're not but pretend you are). That is becuase you can write color in a multitude of ways.

  • Named Colors

    • Named colors are the simpliest way to code colors, but also the most limited. You simpily type the name of a color that is already implemented into CSS and you're good to go! It is useful for simple colors like red or blue, but if you want to get more funky with it the latter choices would suit you much better.

  • Hexidecimal Code

    • Hexidecimal code requires a # followed by a 6 character long sequence of numbers and letters. Every color has one, and this method will expand your pallet tenfold. These codes are pretty easy to find, there's even a color picker on google you can look up. This method would be my go-to if I was more particular about the colors I use.

  • RGB Scale

    • The RBG (red, green, blue) scale is longer than hexidecimal codes, but it does have one upside; it can get transparent with it. This can be done by typing { rbg(R G B / %) } With R being how much red is present, G how much green, B how much blue, and the precent being the visibility of the color. 100 for fully visible, 0 for invisible.

  • HSL Scale

    • HSL stands for hue, saturation, and lightness. It isn't as popular as the first three options, but it probably has its uses if you wanted to play with those specfic values. HSL is written as { hsl(H S% L%) } with the values corresponding to the order the letters are listed. It can also add transparency through the same method as the RGB scale.
