Images: HTML

Inserting images onto your website using HTML code is a relatively straightforward process. The basic format is <img src="img-url" alt="a descriptor in case the link does not work, or for screenreaders."> To allow the image url to function properly, you must upload an image into the folder where the HTML file is housed. This can easily be done through github by uploading it as a file. I don't use any other coding software, so you're on your own for any others.

Images: CSS

Using images as a background in CSS is a way to display text over an image. The basic code format for this method is p { background-image: url("img-url"); } Similarily to HTML, the image file must be uploaded into the folder you are coding in for the link to work properly. You can also use gradients! imstead of a url, add { background-image: linear-gradient(color, color) } That's for very basic graidents, but there are a lot more you can do.

But wait! There's more! When inserting an image through CSS, it's often not gonna look how you'd like it to. You gotta tweak it to make it perfect. { background-repeat } is one of these tweaks. By default, if you resize an image in CSS to be too big, it will fill up that space by repeating the image. if you set this precept to { background-repeat: no-repeat; } it will not do that. Very useful if you ask me. Another is { background-size }. This can help you reszie the background specfically, using measurement units, or by setting it to { background-size: cover; } in which the full image will automatically fill up the dimensions of the element.
