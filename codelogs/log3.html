CSS Media Queries

What is A Media Query?

By using the @media { } tag in css, we can make a media query! Media queries are used when we want to make a page look different under different circumstances, like screen size. It is most useful when designing a responsive website, so your page can look good on both desktop and mobile devices. A website designed for only desktop is far too small when opened on mobile, while a website designed for only mobile would look overwhelming on desktop.

Media Features

  • min-width
    • The min-width feature is usually used when designing a website as mobile-first. It dictates the minimum size that a screen must be for the layout to change from the smallest default. It is recommended to start mobile-first.
  • max-width
    • The max-width feature is usually used when designing a website as desktop-first. It dictates the maximum size that a screen must be for the layout to change from the largest default. It is not recommended to start desktop-first.
  • orientation
    • The orientation feature is used when you want the layout of your website to change when a device is in portrait mode versus landscape mode, like your phone.
  • resolution
    • The resolution is used when you want a website's layout to change depending on the pixel density of a visitors device, often for font-size.
